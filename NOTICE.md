# Notice and attribution

Nav is an independent implementation inspired by the map-based **Wayfinder**
workflow created and taught by [Matt Pocock](https://www.mattpocock.com/).
Wayfinder's useful framing of maps, bounded tickets, dependency-backed
frontiers, and claim-before-work coordination informed Nav's requirements.

Nav is not presented as Matt Pocock's software, and Matt Pocock has not
endorsed this repository. The implementation, adapter protocol, transaction
model, and code in this repository are maintained independently under the MIT
License.
